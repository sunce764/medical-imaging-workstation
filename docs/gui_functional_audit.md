## 首轮功能审计：复现与修复

- **AI 与手动操作冲突**：重置没有取消旧任务，晚到结果会重新填满清空的蒙版；
  手动画笔也会被晚到 AI 覆盖。重置和有效手动编辑现在使旧任务代次失效，编辑接管后保留停止原因。
  重置非空蒙版也保留明确清空的保存意图。
- **绘制上下文错位**：MPR 悬停重绘移除了未完成笔划，切层后松手可能把旧坐标存到新层。
  普通刷新保留预览；换层、工具、平面、序列、模式和重置取消未完成操作。
  非 Axial 视图在落笔前说明限制，避免画完才丢弃。
- **重建来源残留**：新序列恰好同层数、同当前层号时，旧弦图、BP 缓存和结果仍可使用。
  统一来源失效处理；卸下最后一个模体时清空 V1；空载生成弦图入口禁用。
- **显示路径不一致**：未知 HU 单位 CT 的重建参考图没有应用阅片页预览变换，切页后突然泛白。
  两个显示入口现在共用切片变换，原始数组和 HU 分析权限不变。
- **复位与入口状态**：复位遗漏反色、厚层投影和旧探针读数；空载 Cine 可点；
  套索统计入口与矩形 / ROI 的 HU 条件不一致。相关控件状态已统一，套索工具提示也与实际截取功能一致。
- **导出结果不实**：PNG 保存返回 false 后仍可能显示“图像已保存”。现在检查真实返回值并报告失败。
- **深色系统弹窗**：模型卡 / 三维窗口曾假定系统总是浅色，macOS 深色模式下正文对比度仅约 1.16:1。
  显式统一背景和文字色；深 / 浅系统 palette 下三维普通文字最低 6.68:1，模型卡普通文字 10.24:1。
  原生截图也已目视复核；测试不把 HTML 内每种强调色都计入该数值。
- **长状态被截断**：AI 结果状态未换行；重建耗时固定一行导致取消说明看不全。现已允许完整换行。

新增 / 扩展回归集中在 `tests/test_gui.py` 中的 `test_full_ui_state_audit`、
`test_drawing_context_audit`、`test_export_failure_and_status_audit`、
`test_ct_window_preview_without_hu`、`test_mesh_dialog_text_is_readable`。

## 后续专项：维度、方向与链路（2026-09-04）

基线 `913d423f9f40410b01e9ba7ea27cb348f43558fa`。按三个互补层次完成复查：

### 实测缺陷与修复

- **三维方向**：顶点按 `(z,y,x)=(Superior,Posterior,Left)` 存储，原相机却当作 xyz 旋转。
  右 / 左视角实际从头 / 足侧看，俯仰只在屏幕内滚转。现显式建立患者方位到相机的变换；
  提取网格、形状定量和 STL 坐标未改。用三边不同的长方体验证前 / 右 / 上按钮及实际渲染比例。
- **AI 网格与异常回退**：极短轴按原 spacing 比例插值可能得到 0 层，违背已计算的非空目标尺寸；
  回映射失败后又保留模型网格半成品，误报成功。现兑现目标尺寸，并在异常分支清除 mask / confidence
  后真正降级。合成模型只替代 ONNX session，实际重采样、轴变换、回映射和回调代码照常执行。
- **物理显示比例**：延迟适配、布局与 resize 的 `fitInView` 覆盖了各向异性比例；
  MPR 转随访 / 重建还会继承旧平面的间距。适配入口统一保留物理比例，各图像来源显式安装自身间距。
- **随访可比条件**：同 shape、不同 spacing 仍会计算差值；无重叠 z 覆盖时把端点当同层；
  非方形像素的索引空间旋转被当作物理刚性变换。现要求矩阵尺寸、行列间距和 z 覆盖可比，
  否则只并排显示并清除旧 V3 差值图。同网格非方形像素仅做平移，标题说明限制。
